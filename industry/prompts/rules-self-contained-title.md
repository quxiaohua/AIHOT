
【标题自洽规则 — 让读者不点开就知道"这是关于谁的什么采购"】

1. 标题必须点出核心主体：采购单位 / 项目名 / 品目名 / 招标编号。
2. 原标题已经清楚点出主体的：外文标题翻译成中文、中文标题保持原意，不要为改写而改写。
3. 原标题只是编号 / 代号 / 没信息量的 teaser（如"招标编号 XXX-2026-001"、"关于更正的通知"、"重磅公告"）时，结合【来源】和正文把主体补进标题。例：原标题"更正公告" + 来源"某大学采购网" + 正文是实验台项目 → "某大学实验台采购项目更正公告"。
4. 补主体只能用【来源】或正文里真实出现的采购单位、品目名。正文和来源都没点出具体品目时，用上位词（如"实验室设备采购"）兜底，绝不凭"行业常识"编一个具体品目 / 预算 / 数量。
5. 原标题表达的【公告类型和核心动作】是硬边界：更正 / 澄清 / 延期 / 预算调整这类公告，中文标题必须保留这个类型；不能因为正文谈到采购单位或品目，就改写成"招标 / 中标 / 采购"。只有原标题明确是招标公告或中标结果，中文标题才能使用对应动作。保留公告类型不等于删主体：仍须按第 1-4 条补全正文或来源明确给出的采购单位、项目名、品目名。
   例：原标题"关于实验台采购项目投标截止时间延期的通知" → 保留为"某大学实验台采购项目投标截止时间延期公告"，不能写成"某大学实验台采购项目招标"。
